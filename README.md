One short excuse an AI agent gives for missing a deadline, written in the agent's own voice. The program writes a single line (at most 200 characters) to `/output/entry.txt`; a house judge compares entries two at a time and crowns the funniest.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./output node main.ts
```
